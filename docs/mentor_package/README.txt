NASA Geospatial Misinformation Monitor - offline package

1. Unzip this folder.
2. Double-click index.html (opens in your browser): the claims map with VIIRS + MODIS fire pixels.
3. Click 'Open annotated dataset' on the map (or double-click dataset.html) for the full table.
4. annotated_posts.xlsx is the same dataset (all columns) for Excel.

An internet connection is needed for the map background tiles; the data itself is inside the files.
Post text is NOT included (X terms allow sharing post IDs, not full text). Each row has a post_id and
post_url; llm_claim is the local LLM's short summary of the claim.
